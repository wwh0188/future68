## 功能与边界

- 曲线详情的「拨杆」可在明确确认后发送机器拨杆配方；首页按设备显示本 App 的最近发送记录。`0x08` 单次发送严格限制在已核对格式、固件和新鲜空闲状态；设置同步也不能证明完整配方回读。界面不把 GATT 成功或本地快照当作机内持久保存确认，未知结果不自动重发；确认框说明拨杆使用系统温度且目标液重不保存到机器。
- 自定义曲线支持原五个本地快捷槽位。一键萃取默认关闭，首页与设置同步；打开后快捷槽或上一杯的「使用」可尝试启动。温度、秤、机器状态或配方门禁不满足时只导航，不保存稍后自动出水意图；最终实际派发继续检查当下许可。
- 萃取页显示实时秤读数，仅本杯确认去皮后显示对应出液重，并在结束后冻结该杯读数。基线绑定控制器/本杯序号、秤连接代次及成功去皮后的新数据，不借过期读数或另一杯零点推断液重。
- 历史优先显示真实机器整数计时；没有该证据时明确显示采样覆盖，保留记录历时。旧记录缺失的信息不伪造成机器计时，人工手动萃取仍是观测记录。
- 用户草稿支持删除及撤销。删除使用原子归档状态并清理关联快捷引用，保留旧名称与历史；撤销仍须匹配删除凭据和文档快照。现有存储 wrapper1 可继续读取；只有归档/失效引用非空时才写 wrapper2。单条私人曲线 schema1～4 与上游 configuration schema3 仍不混用。
- 统一开关外观、隐藏空拨杆卡、修正紧凑首页卡片及旧 Android 定位关闭的扫描提示；通用扫描显示机器和秤。采纳晚开机连接恢复及 Acaia/Timemore/DiFluid 残帧边界修复，仍保留只读和控制能力隔离。

Felicita ART 默认可写和旧 ID 别名、去皮后新零、重量新鲜度、至少 7 秒按重规则、关闭不确定锁存及默认只读策略保留。个人此前未开放的 DiFluid 目标控制不因上游测试而开放；新的回归使用公开布局自主构造数据，不复制其他用户诊断或采集标识。保留个人更明确的去皮等待/未知提示，其余相关语言更新跟进上游。
