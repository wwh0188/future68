# 个人 V9：从官方曲线截图导入参数

设置中的「导入曲线技巧 ↗」会打开本页。本教程适用于「OpenHOYI 77 扩展」个人版；原版的 configuration schema3 不是个人版格式，请使用这里的提示词。

1. 拍下曲线名称、说明、温度、目标液重、整体变压/变流和逻辑、全部启用段的目标/单位/水量，以及总量、闷蒸、首段秒数和补偿。页面装不下时分几张拍，包含模式按钮状态。
2. 将 [个人版提示词](curve-import/personal-photo-to-json.zh-CN.txt) 与截图一起交给支持读图的助手。缺失或模糊字段应先补充，不能凭曲线图猜测。
3. 将完整结果保存为 UTF-8 的 `.json` 文件，在 App 曲线库选择导入参数，核对预览中的模式、单位、每段水量、目标液重和说明，再保存。
4. 导入只增加本地曲线，不会启动或发送到机器。选择使用、拨杆或开始萃取仍走对应检查。编辑已有曲线后保存为新曲线，原曲线保留。

说明栏可记录磨豆机刻度、粉碗与粉重；可见原说明和用户补充内容应完整保留。若只想从零手工编辑，也可直接在曲线库创建或复制配方。

个人格式的顶层 `schema` 固定为 4，模式与说明等字段直接放在顶层，不使用 `configuration`。示例：[压力曲线](curve-import/examples/pressure.json)、[首段流量曲线](curve-import/examples/flow.json)。示例只说明格式与单位，不能用来补齐照片缺项；App 保存时可能规范化为等价的个人 schema3。

首段水量 0 mL 配合正秒数仅表示按时间切换，实际仍有流量，不保证 0 bar。接秤且设置目标重量时，现有机器水量上限取基础总量与目标克重四倍的较大值。离线格式校验通过不代表真实机器已验证执行；仍需核对实际曲线和停止效果。
